Quick start

Get from pip install to a tinkring LED on your desk in under five minutes. The tinkr CLI is the entire v1.0 product; everything else (Tauri shell, marketplace, web UI) is layered on top.

Reading time: 4 min Last updated: 2 days ago By: @ronie

1. Install #

Tinkr runs on macOS, Linux, and Windows. It requires Python 3.11 or later.

# macOS / Linux
pipx install tinkr-micropython

# Windows (PowerShell)
pip install --user tinkr-micropython

If you don't have pipx, the README on GitHub has a one-line curl | bash installer.

ℹ Note

Tinkr does not require sudo. All serial-port access on macOS and Linux goes through pyserial, which uses the standard user groups. On Linux, add your user to dialout if you haven't already.

2. Initialize a project #

Create a new directory and let Tinkr scaffold the project memory.

mkdir kitchen-sensor && cd kitchen-sensor
tinkr init
✦ Tip

Run git init right after tinkr init. The project repo is the memory — every change to tinkr.toml and .tinkr/lock.toml should be a commit.

3. Add a hardware plugin #

Plugins give Tinkr the ability to talk to a specific chip family. The four free plugins ship with the CLI; everything else is opt-in via the marketplace.

tinkr plugin add tinkr-esp32
# Resolving tinkr-esp32 from registry... ✓
# Found 1.2.3 (latest stable, MIT, tinkr ≥0.2 <0.4)
# Installed tinkr-esp32@1.2.3.

4. Find your device #

Plug your board in over USB, then:

tinkr device scan
# /dev/cu.usbserial-1410  ESP32-S3-DevKitC-1  [tinkr-esp32]  → esp32s3-left
tinkr device use esp32s3-left --nickname "kitchen sensor"

5. Deploy #

Open main.py, write the LED-tinkr code, save, and deploy:

# main.py
from machine import Pin
import time

led = Pin(48, Pin.OUT)

while True:
    led.value(1)
    time.sleep_ms(500)
    led.value(0)
    time.sleep_ms(500)

Then run:

tinkr project deploy
✓ Result

The deploy stages flash, upload, and reboot the device in one command. When the LED starts tinkring, you have a working Tinkr project.

What's next? #

  • Open the Tauri shell to get a Monaco editor and an agent chat panel.
  • Browse the marketplace for plugins that add more chip families.
  • Read the plugin spec if you want to build a hardware plugin of your own.
  • When your project deploys successfully, the capture layer will offer to save it as a recipe for the community.
