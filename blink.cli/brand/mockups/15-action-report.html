+ <!-- Tinkr Mockup 13 — Wordmark Animation States -->
+ The Tinkr wordmark `t●nkr` is the agent's face. Different
+ operations get different animation states, so the user always
+ knows what the agent is doing without reading the text.
+ 8 states. The mark itself never changes shape — only the
+ dot's animation. Cyan letters stay. Amber dot animates.
+ 1. idle — 1Hz pulse, the "tinkring LED" (default)
+ 2. thinking — 0.6s quick pulse, faster
+ 3. reading — slow left-right scan (the "scanner")
+ 4. writing — 3-dot typing wave
+ 5. searching — rotating ring around the dot
+ 6. flashing — amber to cyan rapid flash (firmware flash)
+ 7. compiling — segments rotating around the dot
+ 8. done — checkmark, then settle to idle
+ .mark.idle .led {
+ animation: idle 1s ease-in-out infinite;
+ }
+ @keyframes idle {
+ 0%, 100% { opacity: 0.55; transform: scale(1); }
+ 50% { opacity: 1; transform: scale(1.15); }
+ }
