layout

Card list, not table

A scanned board is a rich object — chip model, port, last project, KB entries, plugin compatibility. A flat table would lose 60% of that. Cards carry: board SVG, name + chip + port, status badge, last-seen, action cluster, plugin-version compatibility strip.

a11y

Color is never the only indicator

Status badges combine color, text, and a leading icon (e.g. red badge + "Error" + ✕). The card list is a role="listbox"; arrow keys move selection, Enter opens the details panel, Escape closes it.

brand

Amber = the action

"Scan for devices" is the only amber element on the surface — the ship it color, reserved for the moment a user commits to a hardware workflow. The 4 device cards stay in the cyan/violet/status palette to keep the semantic meaning clear.
