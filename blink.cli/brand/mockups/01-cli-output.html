A terminal that feels like a developer tool.

The tinkr CLI is what ships on day one. Every screen below is a simulated terminal output — same NDJSON protocol, same color semantics, same stage-based progress you'll see in your own shell. No mock data, no fake screenshots: this is the contract.

    code:     OSError_ETIMEDOUT
    category: i2c
    device:   esp32s3-left

  ● kb suggestion   2 matches in the community knowledge base

  ▸ i2c-scan-returns-empty-pullups-missing  — score 0.94  ✓ verified
    Missing or weak pull-up resistors on SDA / SCL. Add 4.7 kΩ from each line to 3.3 V.
    → run tinkr knowledge fix i2c-scan-returns-empty-pullups-missing

  ▸ i2c-wrong-pins-esp32s3                  — score 0.71
    ESP32-S3 default I2C pins are GPIO8 (SDA) / GPIO9 (SCL) on most boards, but some use GPIO1/2.
    → run tinkr knowledge fix i2c-wrong-pins-esp32s3

Light mode is opt-in for accessibility. The CLI defaults to dark because 95% of developers run dark terminals. Light mode uses the same semantic colors, just inverted luminance.
