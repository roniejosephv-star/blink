ESP32-S3 — flash MicroPython over USB-CDC

⏳ pending review

Flash MicroPython firmware onto a stock ESP32-S3 using the built-in USB-CDC bootloader — no external programmer, no esptool.py dance, just the USB-C cable. This is the first thing to run on a new board. Takes ~90 seconds, leaves you at the REPL.

difficulty: intermediate est. time: 5 min firmware: mp ≥ 1.20

Step 1 — Enter bootloader mode

Hold BOOT, tap RESET, release BOOT after 1s. The board enumerates as a USB-CDC device on /dev/cu.usbmodem*.

# wait for the USB-CDC port to appear
$ ls /dev/cu.usbmodem*
/dev/cu.usbmodem14101

✓ verify: the port appears in ls /dev/cu.usbmodem*. The LED on GPIO48 tinkrs 3× on reset.

Step 2 — Deploy the firmware

Run tinkr project deploy — it detects the USB-CDC port, calls esptool.py under the hood, erases flash, writes the firmware, and verifies the checksum.

$ tinkr project deploy
[1/5] detect  /dev/cu.usbmodem14101 · esp32s3 · done 0.4s
[2/5] erase   8 MB flash                  · done 1.2s
[3/5] write    ESP32_GENERIC_S3-…v1.24.1.bin · done 3.1s
