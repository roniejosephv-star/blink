i2c-wrong-pins-esp32s3

ESP32-S3 default I²C pins vary by board — most DevKits use GPIO8/9, but some use GPIO1/2. Check the silkscreen before assuming.

min_firmware: "1.20"

symptoms:
  - "i2c.scan() returns [] (empty list)"
  - "OSError: [Errno 110] ETIMEDOUT on i2c.scan()"
  - "SDA / SCL lines read 0 V with a multimeter"

likely_causes:
  - "No external pull-up resistors on SDA / SCL (the default board has none)"
  - "Pull-up resistors too large (> 10 kΩ) for the bus capacitance"
  - "Pull-ups connected to 5 V instead of 3.3 V (damages the sensor)"

fix_steps:
  - "Add 4.7 kΩ pull-up from SDA to 3.3 V"
  - "Add 4.7 kΩ pull-up from SCL to 3.3 V"
  - "Verify with i2c.scan() and confirm a non-empty list"

verify_steps:
  - "i2c.scan() returns at least one address, e.g. [0x76]"
  - "Reading the sensor's WHO_AM_I register returns the expected ID"
