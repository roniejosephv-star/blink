# deploy with: tinkr project deploy --device esp32s3-left

import time
from machine import Pin, I2C
import network, bme280
from umqtt.simple import MQTTClient

# I2C bus on GPIO8 (SDA) / GPIO9 (SCL) — 4.7kΩ pull-ups required
i2c = I2C(0, scl=Pin(9), sda=Pin(8), freq=100_000)
sensor = bme280.BME280(i2c=i2c)

# onboard LED on GPIO48 — used as a heartbeat indicator
led = Pin(48, Pin.OUT)

def connect_wifi(ssid, psk, timeout=10):
    wlan = network.WLAN(network.STA_IF)
    wlan.active(True)
    wlan.connect(ssid, psk)
    for _ in range(timeout * 10):
        if wlan.isconnected(): return wlan.ifconfig()
        time.sleep_ms(100)
    raise OSError("wifi timeout")

layout

Three panes, no toolbars

Devices left, code center, agent right. The full vertical space belongs to the editor. Cross-cutting concerns (git, device, tests, plugins) live in a 28px status bar — never in a top toolbar.

capture

Status bar, not a popup

The capture badge pulses in the status bar when a trigger fires. Clicking opens a side panel — never a modal. The 5 trigger types (recipe · fix · chip · pattern · publish) are visible chips so the vocabulary is learned by seeing it.

chrome

Native, not web

Title bar shows project name + git branch + chip — the three things you scan first. Light + dark via ⌘⇧L. Window controls (close/min/max) follow the host OS convention. The Tauri shell weighs 8–40 MB, not 200+ MB like Electron.
