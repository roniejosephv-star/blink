layout

REPL + plotter, side-by-side

Iterating on a sensor read needs the typed history AND the live value stream in the same window. The two panes share state — typing temp.value in the REPL doesn't auto-plot, but a single button "plot this" does, and the dropdown is pre-filled with recently-typed expressions.

terminal

The chip's screen

The REPL inherits the sunken surface (#050506 per brand spec) — it's the only place in the shell darker than the canvas. ANSI colors render as styled spans. Error tracebacks highlight the offending line in amber, matching VS Code / PyCharm convention.

capture

One session → one KB entry

The "Capture to KB" button in the bottom strip writes the entire transcript + plotted values + device + plugin version as a single knowledge base entry. One click, one review, one published fact. The keyboard shortcut ⌘⇧C is the same in the CLI and the shell.
