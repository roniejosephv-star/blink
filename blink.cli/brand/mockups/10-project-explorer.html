What this screen is for

It is the home base. Users land here on first launch and on every "no project open" state. The explorer must answer: what can I do here? for a newcomer, and which project do I want? for a returning user — without ever feeling like a different screen.

Why the right rail is first-run only

The stats and cloud-sync card are an upsell surface. Hiding them after the first session keeps the explorer calm and tool-like for power users. Same screen, less chrome. The "Sync to cloud" card uses cyan (brand, not amber) to mark it as a Tinkr product, not a vendor plug.

Project card anatomy

Name + relative time → target chip (the silicon) → status pill (built / modified / not built) → plugin list (3 chips) → sync state (only for git-backed). Hover actions fade in. Every status color is from the locked semantic palette. No drop shadows, no glows — just borders.

The "bl●nk" mark

Lowercase bl + amber LED dot + nk. The dot tinkrs at 1 Hz (suppressed under prefers-reduced-motion). The same mark appears in the title bar, top bar, and the welcome banner. This is the only place the brand breathes.
